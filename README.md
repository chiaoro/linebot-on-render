# linebot-on-render

## 功能

- LINE 主選單的「班表查詢服務」可直接開啟班表查詢儀表板。
- 院務會議請假會快取醫師對照名單；Google Sheets 短暫失敗時會重試並可回退到舊快取。
- 院務會議送件失敗時保留當前步驟，使用者可直接重試，不需重新走完流程。
- 「支援醫師調診單」依序詢問醫師姓名、該醫師科別、原門診日期、新安排及原因。LINE Bot 將科別送至「支援醫師調診紀錄」試算表的 Apps Script Web App；接收程式寫入「調診」分頁，文件產出排程每 5 分鐘處理未產出的紀錄，完成後於 H 欄標記「已產出」。修改接收程式後須更新既有 Web App 部署。
